# DART 기업 분석기

OpenDART API로 사업보고서·반기·분기보고서를 불러와 실적 추이, 밸류에이션, 유동성을 한 화면에서 분석하는 Streamlit 앱입니다.

## 실행

1. https://opendart.fss.or.kr 에서 API 키 발급 (무료, 하루 20,000건)
2. `run.bat` 더블클릭 (최초 실행 시 가상환경 생성·패키지 설치)
3. 브라우저가 열리면 사이드바에 API 키 입력 → 회사 검색 → 보고서 선택 → **분석 실행**

## 다른 사람에게 공유하기 (Streamlit Community Cloud, 무료)

API 키를 서버 Secrets 에 넣으면 사이드바의 키 입력칸이 사라지고, 방문자는 키를 볼 수 없습니다.

1. GitHub 에 새 저장소를 만들고 이 폴더를 올립니다. `.gitignore` 덕분에 `.venv`, `.cache`, `secrets.toml` 은 올라가지 않습니다.
2. https://share.streamlit.io 에 GitHub 계정으로 로그인 → **Create app** → 저장소와 `app.py` 선택.
3. **Advanced settings → Secrets** 에 `DART_API_KEY = "키"` 한 줄 입력 → **Deploy**.
4. 생성된 `https://<이름>.streamlit.app` 링크를 공유합니다.

로컬에서도 같은 방식으로 쓰려면 `.streamlit/secrets.toml.example` 을 `secrets.toml` 로 복사해 키를 넣으세요.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 실적 추이 | 3개년 매출·영업이익·순이익 막대 + 영업/순이익률 선, 증가율. 분기보고서 선택 시 TTM 막대와 누적 YoY. 최근 10~12개 분기 단독 실적과 전년 동기 대비 증가율 |
| PER·PBR 밴드 | 과거 약 6년 주가와 EPS·BPS로 그린 멀티플 밴드(10·30·50·70·90% 지점), 현재 배수의 역사적 위치 |
| 동종업계 비교 | 비교 기업(최대 8개)의 PER·PBR·PSR·EV/EBITDA·ROE·영업이익률과 중앙값. 중앙값을 목표 멀티플로 채우기 |
| 밸류에이션 | EPS·BPS·SPS, PER·PBR·PSR, EV/EBITDA·EV/EBIT, ROE, FCF Yield / 목표 멀티플 적정주가(직접 입력) / S-RIM |
| 유동성·안정성 | 유동·당좌·현금비율, 부채비율, 자기자본비율, 차입금의존도, 순차입금비율, 이자보상배율, Net Debt/EBITDA |
| 적정주가 종합 | 모든 방법의 적정주가를 현재가와 비교하는 Football Field 차트 |
| 재무 데이터 | 자동 매칭된 계정값, DART 원본 재무제표, CSV 다운로드 |

## 계산 기준

- 손익: 사업보고서는 해당 연도, 분기·반기보고서는 **TTM** = 직전 연간 + 당기 누적 − 전년 동기 누적
- 재무상태: 선택한 보고서의 기말
- EV = 시가총액 + 총차입금(옵션: 리스부채) − 현금·단기금융상품 + 비지배지분
- EBITDA = 영업이익 + 현금흐름표의 감가상각비·상각비 (못 찾으면 직접 입력)
- S-RIM = 지배주주지분 + 지배주주지분×(ROE − k) / k  (w=0.9, 0.8 감소 시나리오 포함)

## 한계

- 계정명이 회사마다 달라 정규식으로 자동 매칭합니다. 값이 이상하면 '재무 데이터' 탭에서 원본을 확인하세요.
- 금융업(은행·보험·증권)은 재무제표 구조가 달라 일부 지표가 나오지 않습니다.
- 12월 결산이 아닌 회사는 분기 구분이 어긋날 수 있습니다.
